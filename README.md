# UI Scanner

UI Scanner — инструмент для получения структурированного представления интерфейса рабочего стола без OCR и моделей компьютерного зрения. Он использует системные API доступности, находит видимые интерактивные элементы окон и сохраняет их координаты, типы и текст в JSON.

Одновременно программа делает снимок рабочего стола и наносит на него пронумерованные рамки. Номер на изображении соответствует `id` элемента в JSON, поэтому результат удобно использовать в автоматизации, тестировании и desktop-агентах.

## Возможности

- обнаружение окон рабочего стола;
- получение порядка наложения окон;
- извлечение элементов через Windows UI Automation или Linux AT-SPI;
- отбор интерактивных элементов по типу, состоянию и размеру;
- учёт перекрытия элементов другими окнами;
- нормализация координат относительно размера рабочего стола;
- создание аннотированного снимка экрана;
- экспорт результата в JSON;
- параллельное сканирование видимых окон;
- повторное использование результата обхода внутри объекта окна.

## Для чего можно использовать

- desktop-автоматизация и RPA;
- управление приложениями программными агентами;
- сбор данных для UI-тестов;
- анализ доступности интерфейсов;
- поиск кликабельных областей без OCR;
- подготовка компактного описания экрана для LLM или другой управляющей системы.

## Как это работает

Сканирование состоит из нескольких этапов:

1. UI Scanner получает список окон средствами операционной системы.
2. Определяет их порядок по оси Z.
3. Делает снимок всего виртуального рабочего стола.
4. Для каждого видимого окна получает дерево элементов системного API доступности.
5. Оставляет поддерживаемые интерактивные элементы.
6. Проверяет их положение и видимость с учётом окон, находящихся выше.
7. Присваивает элементам глобальные идентификаторы.
8. Рисует рамки и идентификаторы на снимке.
9. Сохраняет изображение и структурированный JSON в каталог `results`.

На Windows источником данных служит Microsoft UI Automation через `pywinauto`. На Linux используется AT-SPI. Текст берётся из accessibility-свойств приложения, а не распознаётся по пикселям.

## Поддерживаемые элементы

Windows-конфигурация распознаёт следующие основные роли:

- `button`;
- `input`;
- `textarea`;
- `select`;
- `link`;
- `span`.

UIA-типы `Button`, `Edit`, `Hyperlink`, `ComboBox`, `Text`, `MenuItem`, `TabItem`, `ListItem`, `DataItem`, `TreeItem` и некоторые другие приводятся к единому набору ролей.

Linux-конфигурация дополнительно содержит сопоставления для флажков, переключателей, вкладок, пунктов меню, полос прокрутки, слайдеров, деревьев и терминалов.

## Требования

- Python 3.10 или новее;
- Windows 10/11 либо Linux с доступным AT-SPI;
- доступ к интерактивной пользовательской сессии;
- системная библиотека Spatial Index для `rtree`, если она не поставляется готовым wheel-пакетом для используемой платформы.

Основные Python-зависимости:

- `pywinauto`, `pywin32`, `comtypes` — Windows UI Automation;
- `python3-pyatspi`, `python-xlib`, `ewmh` — Linux-интеграция;
- `mss` — быстрый снимок экрана;
- `Pillow` — обработка и аннотирование изображения;
- `rtree` — пространственный поиск пересечений.

## Установка

Создайте виртуальное окружение в каталоге проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Для Windows установите зависимости:

```powershell
pip install pywinauto pywin32 comtypes mss pillow rtree
```

Для Linux набор системных пакетов зависит от дистрибутива. Помимо Python-зависимостей должны быть доступны AT-SPI и средства создания снимка экрана. Для Wayland UI Scanner вызывает `gnome-screenshot`.

## Запуск

Запускайте программу из корня проекта:

```powershell
python main.py
```

Во время выполнения в консоль выводятся количество найденных окон, количество элементов и статистика профилирования.

Результаты сохраняются в:

```text
results/
├── screenshots/
│   └── FULL_DESKTOP_YYYYMMDD_HHMMSS.jpg
└── json-files/
    └── FULL_DESKTOP_YYYYMMDD_HHMMSS.json
```

## Формат результата

JSON содержит массив `elements`:

```json
{
  "elements": [
    {
      "id": 0,
      "type": "button",
      "text": "Сохранить",
      "bbox": [0.725, 0.846, 0.793, 0.884],
      "window": "Редактор"
    }
  ]
}
```

Поля элемента:

| Поле | Описание |
| --- | --- |
| `id` | Идентификатор элемента на текущем снимке |
| `type` | Нормализованная роль элемента |
| `text` | Имя или текст из accessibility API |
| `bbox` | Координаты `[x1, y1, x2, y2]`, нормализованные в диапазоне относительно размеров экрана |
| `window` | Заголовок окна-владельца |

Чтобы получить координаты в пикселях, умножьте `x1` и `x2` на ширину снимка, а `y1` и `y2` — на его высоту.

## Настройка

Основные параметры находятся в `config.py`:

| Параметр | Назначение |
| --- | --- |
| `MIN_ELEMENT_WIDTH` | минимальная ширина элемента в пикселях |
| `MIN_ELEMENT_HEIGHT` | минимальная высота элемента в пикселях |
| `TEXT_OFFSET_Y` | вертикальное смещение номера над рамкой |
| `COLOR_MIN`, `COLOR_MAX` | диапазон случайных цветов аннотаций |
| `SCREENSHOT_DIR` | каталог снимков |
| `JSON_DIR` | каталог JSON-файлов |

Набор распознаваемых ролей и правила преобразования платформенных типов находятся в `elements/element.py`.

## Особенности системных API

UI Scanner получает только те данные, которые приложение публикует через accessibility API. Полнота результата зависит от реализации интерфейса конкретного приложения.

Стандартные Win32, WinForms, WPF, Qt и браузерные интерфейсы обычно предоставляют системное дерево элементов. Интерфейсы на основе canvas, WebGL, игр, удалённого рабочего стола и полностью пользовательской отрисовки могут отдавать неполную структуру или не отдавать её вовсе.

Сканирование выполняется в текущей интерактивной сессии. Для доступа к приложениям, запущенным с повышенными правами, самому UI Scanner также могут потребоваться соответствующие права.

## Программное использование

Сканер можно вызвать из Python-кода:

```python
from scanner import DesktopScanner

scanner = DesktopScanner()
scanner.scan()

for element in scanner.all_elements:
    print(element["id"], element["type"], element["text"])
```

После вызова `scan()` экземпляр содержит:

- `windows` — найденные окна;
- `z_order` — порядок окон;
- `screen_img` — аннотированное изображение;
- `screen_width`, `screen_height` — размер снимка;
- `all_elements` — список найденных элементов;
- `element_global_id` — число назначенных идентификаторов.

## Конфиденциальность

Обработка выполняется локально. UI Scanner не требует подключения к внешнему API и не отправляет снимки экрана или accessibility-данные по сети. Полученные изображения и JSON-файлы могут содержать текст и содержимое открытых приложений, поэтому каталог `results` следует хранить и передавать с учётом чувствительности этих данных.
